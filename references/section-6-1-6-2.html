6.1 Agent Taxonomy

There are two equally valid ways to define an agent within People Assist. The lens you use depends on the problem you are solving. Both are correct and complementary.

Two Lenses, One Truth

Use the Functional lens when designing products, backlogs, personas, and journeys. Use the Technical lens when designing system architecture, platform constructs, and deployment decisions.

Functional View — Product Design
Make a Parallel to a Human

Think of the agentic system the way you think of a human team. A Skill Group is the person. That person has Skills, things they know how to do. Each skill uses Tools to get the job done.

Skill Group → Skill → Tool
Technical View — System Architecture
Agent Hierarchy

Technically, agents are classified by what they control. An Orchestrator routes and coordinates. A Super Agent handles a domain. A Utility Agent executes a single, focused capability.

Orchestrator → Super Agent → Utility Agent
How The Two Views Map To Each Other
Functional → Technical
Skill Group  ≡  Orchestrator Agent (L1)
Skill  ≡  Super Agent (L2)
Tool  ≡  Utility Agent (L3)
When To Use Which Lens
Functional: backlog, personas, journeys, agent naming
Technical: platform design, Copilot construct, deployment

6.2 Current HR Agent Portfolio

The Employee Self-Service Skill Group is anchored by the Digital HR Partner, People Assist's most mature experience agent. Its capabilities span five functional clusters, from core information assistance through to guided task completion, proactive notifications, support workflows, and career development guidance.

The Talent Supply Skill Group is powered by the Digital Talent Connector, the employee-facing agent for talent mobility. Its capabilities span four functional clusters: role discovery and search, role application and management, employee engagement nudges, and personalisation and configuration settings.

The Career Skill Group is powered by the Digital Career Coach, the experience agent responsible for personalised career guidance and development support. Its capabilities span two clusters: career guidance and planning, and opportunities and networking.
